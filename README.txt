LISTER SUITS ERP — HTML STARTER

HOW TO OPEN
1. Download and unzip Lister_Suits_ERP_HTML.zip.
2. Open the extracted folder.
3. Double-click index.html, or open it in Safari/Chrome.
4. Use the navigation links to open Inventory, Customers, and Sales.

WHAT IS INCLUDED
- Dashboard
- Inventory management (add, search, delete suit styles)
- Customer records (add, search, delete)
- Sales records (calculate total, reduce stock)
- Responsive design for desktop and mobile

IMPORTANT LIMITATION
This is a front-end HTML/CSS/JavaScript demonstration. It does NOT need XAMPP or MySQL, and it can be opened directly in a browser. Data is saved in the current browser's localStorage on this device. It is not shared across devices or users, and browser data can be cleared. Do not use this version as a secure production accounting or ERP system.

To make it a multi-user ERP with a real database, login security, and shared records, a server-side backend such as PHP + MySQL is required.
